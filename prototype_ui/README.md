# Pool Predictive Maintenance — Prototype UI

A lightweight demo dashboard for pool water quality monitoring and predictive maintenance.
Supports uploading your own data (CSV/Excel) and manual data entry.

## Quick Start

```bash
cd prototype_ui
pip install flask pandas openpyxl   # if not already installed
python app.py
```

Then open **http://localhost:8050** in your browser.

## Requirements

- Python 3.8+
- `flask`, `pandas`, `openpyxl` (auto-installed on first run if missing)
- The `outputs/master_dataset.csv` file for demo data (generated by `pipeline_v3.py`)
- A modern web browser (Chrome, Firefox, Safari, Edge)

## Features

### 1. Fleet Overview
- Sortable table of all pools with latest pH, chlorine, turbidity readings
- Color-coded urgency status (Immediate / Soon / Routine / Extended) based on regulatory thresholds
- Search by pool name or community
- Summary statistics cards

### 2. Pool Detail View
- Click any pool to see its full reading history
- Line charts for pH, chlorine, and turbidity over time with regulatory bands shaded
- Next visit recommendation (days) based on seasonal baselines
- Chemical prescription (chlorine, pH adjustment, flocculant) with kg amounts
- Volume warning when pool volume is unknown (dosage uses 50 m³ default)

### 3. Time Travel
- Date picker and slider to view fleet status at any historical date
- Shows which pools would have needed attention on that date
- Based on the most recent reading available at the selected date

### 4. Upload Your Own Data (CSV / Excel)
- Click **📁 Upload Data** in the data source bar
- Upload a `.csv` or `.xlsx` file with your pool readings
- **Column mapping**: Your file doesn't need to use the exact column names used internally. After upload, a mapping screen shows all your columns as dropdowns. The system auto-detects common patterns (e.g. columns containing "ph", "chlorine", "date", "pool") so you usually just confirm rather than map manually
- **Supported columns**:
  | Field | Required | Examples of auto-detected names |
  |-------|----------|---------------------------------|
  | Pool ID | ✅ | `pool_id`, `pool`, `id`, `piscina` |
  | Date | ✅ | `date`, `reading_date`, `fecha`, `timestamp` |
  | pH | At least one measurement | `ph`, `p.h.` |
  | Free Chlorine | At least one measurement | `chlorine`, `cl`, `cloro`, `free_chlorine` |
  | Turbidity | At least one measurement | `turbidity`, `turb`, `ntu`, `turbidez` |
  | Pool Volume (m³) | Optional | `volume`, `vol`, `pool_volume_m3` |
  | Community | Optional | `community`, `location`, `urbanizacion` |
- After mapping, the system parses dates flexibly (supports `YYYY-MM-DD`, `DD/MM/YYYY`, `MM/DD/YYYY`, and more)
- Shows a summary: "Loaded X rows across Y pools. Z rows skipped" with details on skipped rows
- The uploaded data replaces the demo data — all dashboard features work against it

### 5. Manual Data Entry
- Click **✏️ Add Reading** to open the manual entry form
- Fields: Pool ID (with autocomplete for existing pools), Community Name (optional), Date, pH, Chlorine, Turbidity, Pool Volume
- Validates ranges (pH 0–14, chlorine/turbidity non-negative)
- New readings are immediately reflected in the fleet table and pool detail charts
- Manually entered readings appear as **purple triangles** (▲) in the charts and show a "✏️ Manually entered" tooltip, so they are visually distinguishable from original data

### 6. Data Source Switching
- The top bar shows which dataset is active (Demo or uploaded filename) and the row/pool count
- **Reset to Demo**: Click to restore the original bundled dataset
- **Privacy note**: Data is loaded in-memory only and is not saved or transmitted anywhere. It resets on server restart.

## Regulatory Reference

Thresholds are based on **Real Decreto 742/2013** (Spanish national regulation):
- Free chlorine: 0.5–5.0 mg/L (safety range)
- pH: 7.2–8.0
- Turbidity: ≤ 5 NTU

## Architecture

- **Backend**: Flask (single lightweight Python server)
- **Frontend**: Vanilla HTML/CSS/JavaScript with Chart.js for visualizations
- **Data**: Demo data loaded from `outputs/master_dataset.csv` at startup; user uploads parsed with pandas
- **API Endpoints**:
  | Method | Endpoint | Description |
  |--------|----------|-------------|
  | GET | `/api/status` | Current data source info |
  | GET | `/api/fleet` | Fleet overview (optional `?date=` filter) |
  | GET | `/api/pool?id=...` | Pool detail + history |
  | GET | `/api/dates` | Date range for time travel |
  | GET | `/api/pool-ids` | All pool IDs (for autocomplete) |
  | POST | `/api/upload` | Upload CSV/XLSX, returns columns for mapping |
  | POST | `/api/map-columns` | Confirm column mapping, rebuild dataset |
  | POST | `/api/add-reading` | Add a single manual reading |
  | POST | `/api/reset` | Reset to demo data |
