# Pool Predictive Maintenance — Prototype UI

A lightweight demo dashboard for pool water quality monitoring and predictive maintenance.

## Quick Start

```bash
cd prototype_ui
python app.py
```

Then open **http://localhost:8050** in your browser.

## Requirements

- Python 3.8+ (no additional packages needed — uses only standard library)
- The `outputs/master_dataset.csv` file (generated by `pipeline_v3.py`)
- A modern web browser (Chrome, Firefox, Safari, Edge)

## Features

### 1. Fleet Overview
- Sortable table of all pools with latest pH, chlorine, turbidity readings
- Color-coded urgency status (Immediate / Soon / Routine / Extended) based on regulatory thresholds
- Search by pool name or community
- Summary statistics cards

### 2. Pool Detail View
- Click any pool to see its full reading history
- Line charts for pH, chlorine, and turbidity over time with regulatory bands shaded
- Next visit recommendation (days) based on seasonal baselines
- Chemical prescription (chlorine, pH adjustment, flocculant) with kg amounts

### 3. Time Travel
- Date picker and slider to view fleet status at any historical date
- Shows which pools would have needed attention on that date
- Based on the most recent reading available at the selected date

## Regulatory Reference

Thresholds are based on **Real Decreto 742/2013** (Spanish national regulation):
- Free chlorine: 0.5–5.0 mg/L (safety range)
- pH: 7.2–8.0
- Turbidity: ≤ 5 NTU

## Architecture

- **Backend**: Pure Python HTTP server (`http.server`) — no frameworks needed
- **Frontend**: Vanilla HTML/CSS/JavaScript with Chart.js for visualizations
- **Data**: Reads directly from `outputs/master_dataset.csv` at startup
- **API**: Three JSON endpoints: `/api/fleet`, `/api/pool?id=...`, `/api/dates`
