# outputs/

Generated artifacts from training runs.

| File | Description |
|---|---|
| `master_dataset_v6.csv` | Cleaned, merged, feature-engineered dataset (regenerated each run). |
| `shap_summary_*_next.png` | SHAP feature-importance plots for the chlorine / pH / turbidity models. |

These files are regenerated by `python -m ml.training.train`. Historical / superseded
outputs are removed during cleanup rather than retained here.
