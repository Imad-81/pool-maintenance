# models/

Contains trained XGBoost model artifacts, organized as versioned run directories.

## Layout

- `latest.json` — pointer to the active run (`{"active_run_id": "<run-id>"}`). The
  backend's `PredictionService` reads this to hot-swap models after a retrain.
- `<run-id>/` — one directory per training run (e.g. `v6-setpoint-v2/`), each holding:
  - `xgb_chlorine_next.json` — Free Chlorine regressor
  - `xgb_ph_next.json` — pH regressor
  - `xgb_turbidity_next.json` — Turbidity regressor
  - `preprocessor_v6.pkl` — fitted scikit-learn `ColumnTransformer`
  - `inference_config_v6.json` — feature names, fill values, regulatory thresholds,
    client targets, and the post-treatment setpoint

All files are generated by `python -m ml.training.train` (or `python pipeline_v6.py`).
Non-promoted runs are archived under `models/archive/` automatically.

## Regulatory basis

Real Decreto 742/2013 (national) + Decreto 85/2018 (Comunitat Valenciana).
